# ⚡ CodeQuest Nexus

> A academia futurista de programadores.

Plataforma de aprendizado de programação gamificada com visual cyberpunk AAA.

## 🚀 Stack

- **React 18** + **TypeScript**
- **Vite** (build ultrarrápido)
- **TailwindCSS** (estilização)
- **Framer Motion** (animações)
- **Zustand** (state management)
- **React Router v6** (roteamento)
- **Lucide React** (ícones)

## 📦 Instalação

```bash
# Instalar dependências
npm install

# Rodar em modo dev
npm run dev

# Build de produção
npm run build

# Preview do build
npm run preview
```

## 📁 Estrutura

```
src/
├── components/
│   ├── ui/            # Primitivos (Button, Card, Input...)
│   ├── layout/        # AppShell, Sidebar, TopBar...
│   ├── effects/       # Partículas, Hologramas, Glitch...
│   ├── gamification/  # XPBar, LevelDisplay, Streak...
│   └── auth/          # GoogleButton
├── pages/             # Páginas da aplicação
├── stores/            # Zustand stores
├── hooks/             # Custom hooks
├── lib/               # Utils + Mock API
├── types/             # TypeScript types
└── constants/         # Dados estáticos
```
